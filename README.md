## Мета роботи

Навчитися використовувати колекції об'єктів для зберігання, пошуку та видалення об'єктів.

## Предметна область

Відеоігри. Клас `VideoGames` (з попередніх робіт) описує гру:

| Властивість | Тип | Обмеження |
|---|---|---|
| `Name` | `string` | 2-50 символів |
| `Genre` | `GameGenre` | значення переліку (Action, Adventure, RPG, Strategy, Sport, Horror, Simulator) |
| `Rating` | `double` | від 0 до 5 |
| `ReleaseYear` | `DateOnly` | не пізніше за сьогоднішню дату |
| `Price` | `double` | більше 0 |

Також у класі є властивості `Publisher`, `CountPlayers`, `IsTopTier`, статичні члени (`CreatedObjectsCount`, `DefaultPlatform`, `CalculateDiscountedPrice`) та методи `Parse`, `TryParse`, `ToString`, `StartGame`, `ExitGame`.

## Що змінено порівняно з Lab-5

1. Масив `VideoGames[]` замінено на колекцію `List<VideoGames>`. Запитувати максимальну кількість ігор більше не потрібно, список збільшується автоматично.
2. Додавання, видалення та пошук виконуються методами колекції `List<T>`:

   | Операція | Метод `List<T>` |
   |---|---|
   | додати гру | `Add` |
   | видалити за індексом | `RemoveAt` |
   | видалити всі ігри жанру | `RemoveAll` |
   | знайти за жанром або роком | `FindAll` |

3. Логіку, яка не залежить від `Console.ReadLine()` і `Console.WriteLine()`, винесено в окремі статичні методи класу `Program`. Методи меню лише зчитують ввід, викликають ці методи й виводять результат.
4. До тест-проєкту додано тест-клас `Test_Program_Collections`.
5. Виправлено помилку в меню: після некоректного вводу (букви замість числа) програма більше не завершується, а просить ввести значення ще раз.
6. Простір імен `GameGenre` змінено на `oop_lab_1`.

## Методи, які не залежать від Console

| Метод | Опис |
|---|---|
| `AddGame(List<VideoGames>, VideoGames)` | додає гру до списку, для `null` кидає `ArgumentNullException` |
| `RemoveGameAt(List<VideoGames>, int)` | видаляє гру за індексом (з 0), повертає `false` для некоректного індексу |
| `RemoveGamesByGenre(List<VideoGames>, GameGenre)` | видаляє всі ігри жанру, повертає кількість видалених |
| `FindByGenre(List<VideoGames>, GameGenre)` | повертає новий список ігор заданого жанру |
| `FindByYear(List<VideoGames>, int)` | повертає новий список ігор заданого року, для року поза межами 1900-поточний кидає `ArgumentOutOfRangeException` |
| `TryGetGenre(int, out GameGenre)` | перетворює число 1-7 на жанр, повертає `false` для некоректного числа |

## Меню програми

```
1 – Додати об'єкт
2 – Переглянути всі об'єкти
3 – Знайти об'єкт
4 – Продемонструвати поведінку
5 – Видалити об'єкт
6 – Продемонструвати static-методи
0 – Вийти з програми
```

- **Додати** гру можна покроково або одним рядком формату `Назва;Жанр;Рейтинг;Дата(РРРР-ММ-ДД);Ціна` (через `TryParse`).
- **Знайти** гру можна за жанром або за роком випуску.
- **Видалити** можна за номером у таблиці або всі ігри певного жанру.

## Unit-тести

Проєкт тестів використовує MSTest. Запускаються як нові тести, так і тести з Lab-5.

- `Test_Video_Games` містить тести класу `VideoGames` з попередньої роботи.
- `Test_Program_Collections` містить 26 тестових методів для нових методів:
  - `AddGame`: додавання, додавання в порожній список, `null` замість гри та списку;
  - `RemoveGameAt`: коректний індекс, перша й остання гра, індекси `-1`, `4`, `100`, порожній список, `null`;
  - `RemoveGamesByGenre`: дві збіги, один збіг, немає збігів, порожній список, `null`;
  - `FindByGenre`: є збіги, немає збігів, оригінальний список не змінюється, `null`;
  - `FindByYear`: є збіг, немає збігів, порожній список, роки `0`, `1899`, `-5`, майбутній рік, `null`;
  - `TryGetGenre`: числа 1, 3, 7 та некоректні 0, 8, -1, 999.

Тестуються як коректні, так і некоректні значення.
